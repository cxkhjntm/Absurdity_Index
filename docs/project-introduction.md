# 项目介绍

ABSURDITY INDEX // 荒谬指数 是一个赛博朋克风格的个人荒谬事件追踪系统。它把日常工作里那些重复、低效、令人无语的流程，转化成可以记录、评分、统计和回顾的游戏化内容，让“吐槽”变成一种有仪式感的数字化归档。

这个项目的核心目标，不只是记录事件，而是把荒谬感本身可视化、可量化、可积累：每一条事件都会对应荒谬值、等级、成就和周报统计，用户还能通过 AI 生成事件分析、成就名称和等级称号，让整套体验更像一个带黑色幽默的个人仪表盘。

## 项目亮点

- 记录荒谬事件，自动累计荒谬值。
- 通过成就系统强化“收集感”和“成长感”。
- 用周报和图表把一周的荒谬经历整理成可视化结果。
- 支持 OpenAI 兼容 API，可按需启用 AI 分析和命名能力。
- 数据保存在浏览器本地，适合轻量使用和快速体验。

## 适合场景

- 想把工作中的无奈事件整理成可回顾清单的人。
- 想做一个带强风格化视觉和游戏化机制的前端项目的人。
- 想体验本地优先、AI 可选接入的个人记录应用的人。

## 一句话总结

这是一个把职场荒谬感做成可记录、可统计、可展示的赛博朋克风前端应用。
